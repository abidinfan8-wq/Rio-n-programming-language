# Security Policy

If you discover a security vulnerability in RIO, please report it privately to the maintainers by emailing `abidinfan8@gmail.com` with the subject line: "RIO security report".

Please include:
- A clear description of the issue and the impact
- Steps to reproduce
- Proof-of-concept or test case (if applicable)

After a fix is available, the maintainer will coordinate public disclosure and a patched release.
